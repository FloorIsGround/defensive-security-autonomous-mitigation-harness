# Luna High evidence-selection pilot

Run six independent synthetic listener incidents once each using GPT-6 Luna High on Standard Responses. The operator identifies a TCP port and asks whether the service associated with the new listener is currently running. The investigator receives the normal worker tool descriptions and scoped incident evidence. The operator supplies neither the unit name nor a collector, watch ID, watch specification or expected state. Each snapshot also contains unrelated listeners. Vary the target port, service name and position. Run two active cases, two inactive cases, one unknown state and one withheld sample.

Score selection when the signed bundle contains exactly one incident watch and its host, unit and state collector match the target inferred from the socket evidence. Require a durable follow-up for that watch. Deliver the hidden outcome only after the initial run has returned. For a delivered sample, require the expected persisted interpretation and a citation to exactly the newly delivered observation. For the withheld sample, require a pending question and no finding with a determinate interpretation. Require a valid audit ledger for each pass. Inspect early findings for premature conclusions separately. Keep failures in the denominator. Give each initial investigation at most four turns, one watch proposal, 24,000 total tokens and 75 seconds. Give reassessment one turn, 4,096 total tokens and 60 seconds. Limit individual requests to 25 seconds. No model retries or remediation. This tests choosing evidence for a known investigative question.
